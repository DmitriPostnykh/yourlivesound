# Stage boundary storyboard

This folder is a temporary art-direction workspace for the landing-stage intro.
The glowing yellow horizontal line marks the proposed near edge of the mirrored
stage floor. It is intentionally a guide, not a production design element.

All eight frames were captured from one uninterrupted local replay at a
749 × 934 browser viewport. Each image is cropped to the 749 × 608 stage area.

| Nominal time | Captured at | What is visible |
| --- | ---: | --- |
| 0 s | 0.13 s | Empty stage and the proposed front boundary |
| 1 s | 1.11 s | The first three front-facing spotlights |
| 2 s | 2.13 s | Ten spotlights in the left-to-right cascade |
| 3 s | 3.14 s | All fifteen spotlights and the resting equalizer strip |
| 4 s | 4.06 s | The first beams aim down; the first letter starts to appear |
| 5 s | 5.08 s | Twelve beams are aiming; eight title positions are visible |
| 6 s | 6.11 s | All beams are down and all title positions are visible |
| 7 s | 7.21 s | The equalizer and the moving stage rig are live |
